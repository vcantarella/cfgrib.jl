    CfGRIB.jl

    Description

    CfGRIB.jl is a julia interface to map GRIB files to the Unidata's Common Data Model v4 following the CF Conventions.

    This package is based on the python implementation in cfgrib.py and closely follows the approaches of that package, but in Julia instead. Parity tests are automatically performed between the two to ensure that the data returned by the Julia version is equivalent to that from Python.

    In Python xarray has come out to be a standard way to implement named arrays, however as Julia is a much younger language no stable array interface has been adopted by the community yet, so the approach here is more flexible and allows for multiple array backends to be used.

    Currently two array backends are supported:

    • AxisArrays
    • DimensionalData

    Load either package alongside CfGRIB.jl and the matching backend switches on (they are package extensions), otherwise only the built-in bare data types are returned.

    Low level access and decoding is performed by calling GRIB.jl which itself calls the ECMWF ecCodes library.

    CfGRIB.jl started at ECMWF as ecmwf/cfgrib.jl, written by Robert Rosca. This repository continues that work.

    Installation

    The package is not on the Julia registry yet, so install it straight from GitHub. GRIB.jl and the ecCodes library come along automatically:

    ] add https://github.com/vcantarella/cfgrib.jl

    For a named-array backend add one of the supported packages as well:

    ] add DimensionalData   # or AxisArrays

    Then:

    using CfGRIB, DimensionalData

ds = DataSet("forecast.grib")
da = convert(CfGRIB.DimensionalArrayWrapper, ds)

    The documentation has an in-depth guide to the package and a worked example of downloading and processing ECMWF open-data forecasts.

    Development and Contribution

    Clone the repository and run the tests from its project:

    git clone https://github.com/vcantarella/cfgrib.jl
cd cfgrib.jl
julia --project -e 'using Pkg; Pkg.instantiate(); Pkg.test()'

    The parity tests compare against Python's cfgrib, which the test suite installs into a Conda environment on first run.

    Code follows the Blue style and CI checks it with JuliaFormatter. Format before committing with:

    julia -e 'using JuliaFormatter; format(".")'
